# awg-telegram-bot

Telegram-бот на aiogram 3 для управления профилями AmneziaWG на своём сервере:
создаёт клиентские конфиги (файл `.conf` + QR-код), удаляет их и показывает список.

## Команды

| Команда | Что делает |
|---|---|
| `/new <имя>` | создаёт профиль: ключи, свободный адрес, пир на сервере; присылает `.conf` с описанием адреса, сервера и инструкцией по импорту |
| `/delete <имя>` | удаляет профиль (с подтверждением), он перестаёт работать сразу |
| `/list` | список профилей, последний вход и трафик |

Имя: латиница, цифры, `_` и `-`, до 32 символов.

## Как это устроено

- `bot/bot.py` — сам бот. Не имеет прав root и не трогает конфиг напрямую.
- `server/awg-peerctl` — небольшой скрипт от root, который правит `/etc/amnezia/amneziawg/awg0.conf`
  и интерфейс через `awg set`. Бот вызывает его через `sudo`, разрешён только этот скрипт и только
  пользователю `awgbot`. Имена проверяются регуляркой, блокировка файла защищает от гонок.
- Приватные ключи клиентов на сервере не хранятся: бот присылает файл и забывает его.
- Бот отвечает **только** Telegram-ID из `ADMIN_IDS`, остальных игнорирует.

## Требования

- Ubuntu/Debian с уже настроенным AmneziaWG (интерфейс `awg0`, `/etc/amnezia/amneziawg/awg0.conf`).
- Python 3.10+, доступ сервера к `api.telegram.org`.

## Установка

1. В Telegram откройте `@BotFather` → `/newbot` → задайте имя и username. Сохраните токен.
2. Узнайте свой Telegram-ID, например у `@userinfobot`.
3. На сервере:

   ```bash
   git clone <адрес этого репозитория>
   cd awg-telegram-bot
   sudo bash install.sh
   ```

   Скрипт спросит адрес сервера для клиентских профилей, ID администраторов и токен
   (ввод токена скрыт). Токен сохраняется в `/etc/awg-bot/bot.env` (права `640`, `root:awgbot`).

   Без вопросов (токен потом добавляется отдельной командой, он не попадает в историю shell):

   ```bash
   sudo ENDPOINT=1.2.3.4:443 ADMIN_IDS=123456789 bash install.sh
   sudo awg-bot-set-token
   ```
4. Отправьте боту `/start`.

## Обновление и удаление

```bash
sudo bash install.sh                       # повторный запуск обновит код и спросит настройки заново
sudo systemctl disable --now awg-bot       # остановить
sudo rm -rf /opt/awg-bot /etc/awg-bot /usr/local/sbin/awg-peerctl \
            /etc/sudoers.d/awg-bot /etc/systemd/system/awg-bot.service
sudo userdel awgbot
```

## Заметки

- Профили, созданные вручную до бота, видны в `/list` под именем `peer-<последний октет адреса>`
  и удаляются так же, как остальные.
- Файл `.conf` содержит приватный ключ клиента. Удаляйте сообщение с файлом после импорта.
- Если Telegram недоступен (например, при белых списках на мобильной сети), управлять
  профилями можно по SSH: `sudo awg-peerctl add|del|list`.
